# 공무원 보고서 작성 원칙

## 기본 문체

- 행정업무 담당자가 바로 검토하고 수정할 수 있는 실무적인 문체를 사용한다.
- 긴 서술식 문장보다 핵심이 드러나는 개조식 문장을 사용한다.
- 한 문단에는 하나의 주장, 사실 또는 조치만 담는다.
- 불필요한 주어와 상투적인 표현을 줄인다.
- 명사만 과도하게 나열하지 말고 의미가 분명한 문장으로 작성한다.
- 문장 끝은 문서 전체에서 자연스럽고 일관되게 정리한다.

## 내용 구성

- 추진 배경은 사업이 필요한 이유와 현재 상황을 설명한다.
- 추진 목적은 사업을 통해 달성하려는 상태를 설명한다.
- 세부 계획은 대상, 기간, 방법, 담당, 절차가 드러나도록 작성한다.
- 기대효과는 추진 목적을 반복하지 말고 사업 이후 예상되는 구체적인 변화로 작성한다.
- 행정사항은 실제로 누가 무엇을 언제까지 해야 하는지 작성한다.
- 표는 비교, 일정, 역할 분담처럼 표가 더 효과적인 경우에만 사용한다.

## 사실성과 안전성

- 사용자가 제공하지 않은 날짜, 예산, 인원, 장소, 기관, 성과 수치를 임의로 만들지 않는다.
- 법령과 지침의 정확한 명칭이나 조항을 확신할 수 없으면 단정하지 않는다.
- 자료에서 확인되지 않는 내용이 문서 완성에 필요하면 `[확인 필요: 내용]`으로 표시한다.
- 사용자가 제공한 수치가 서로 충돌하면 임의로 하나를 선택하지 말고 충돌 사실을 확인한다.
- 실제로 수행하지 않은 사업이나 성과를 수행한 것처럼 작성하지 않는다.

## 간결성

- 같은 의미를 추진 배경, 목적, 기대효과에 반복하지 않는다.
- 한 문장이 지나치게 길면 둘 이상의 본문으로 분리한다.
- A4 1쪽 요청에서는 배경과 목적, 세부 계획과 일정처럼 관련 항목을 적절히 통합한다.
- 자료가 많더라도 의사결정과 실행에 필요한 내용을 우선한다.

## 사용자 자료 우선

- 사용자가 제공한 목차, 기관 용어, 사업명, 공식 명칭을 우선 사용한다.
- 기존 초안을 수정할 때는 핵심 의미와 사실관계를 임의로 변경하지 않는다.
- 사용자가 특정 구성이나 표현을 요청하면 출력 규격을 해치지 않는 범위에서 반영한다.
