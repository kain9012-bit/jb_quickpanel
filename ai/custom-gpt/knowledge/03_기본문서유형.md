# 기본 문서 유형

초기 시범판은 계획서, 결과보고서, 일반 보고서·검토자료의 세 유형만 사용한다. 유형은 고정 양식이 아니라 문서를 구성하기 위한 출발점이다.

## 공통 판단 규칙

- 사용자가 문서 유형을 명시하면 해당 유형을 사용한다.
- 유형을 말하지 않아도 요청 목적이 분명하면 AI가 자동으로 판단한다.
- 판단이 애매하고 구성에 큰 차이가 생길 때만 한 번 질문한다.
- 사용자가 기존 목차나 기관 양식을 제공하면 그것을 우선한다.
- 자료에 해당하지 않는 항목은 억지로 만들지 않는다.
- 일정, 예산, 역할 분담, 성과지표 등의 항목은 필요한 경우에만 추가한다.

## 계획서

### 사용하는 경우

- 앞으로 추진할 사업, 행사, 연수, 회의 또는 정책의 실행계획을 작성할 때

### 기본 확인사항

- 추진 목적
- 추진 대상
- 추진 기간
- 주요 내용과 방법

### 필요한 경우 확인

- 장소
- 예산
- 담당 부서와 역할
- 추진 일정
- 성과지표
- 협조사항

### 기본 구성

1. 추진 배경
2. 추진 목적
3. 사업 개요
4. 세부 추진계획
5. 추진 일정
6. 행정사항

예산이나 기대효과가 중요하면 별도 항목으로 추가한다. 단순한 계획이면 추진 배경과 목적을 통합하거나 일정과 세부 계획을 하나의 표로 정리할 수 있다.

## 결과보고서

### 사용하는 경우

- 완료되었거나 일정 기간 추진한 사업의 실행 내용과 결과를 정리할 때

### 기본 확인사항

- 당초 계획
- 실제 추진 기간과 대상
- 실제 수행 내용
- 결과와 성과

### 필요한 경우 확인

- 참여 인원
- 예산 집행
- 만족도와 정량 성과
- 문제점
- 후속 조치

### 기본 구성

1. 추진 개요
2. 추진 내용
3. 추진 결과
4. 성과 및 개선사항
5. 향후 계획

실제 결과가 확인되지 않은 경우 성과를 만들어 내지 않는다. 수치가 없으면 정성적으로 표현하되 근거 없는 성공 평가를 하지 않는다.

## 일반 보고서·검토자료

### 사용하는 경우

- 현황, 문제점, 대안, 검토 의견 또는 의사결정 사항을 보고할 때
- 계획서나 결과보고서로 명확히 분류되지 않는 업무자료를 정리할 때

### 기본 확인사항

- 보고 목적
- 현재 상황
- 핵심 쟁점
- 보고받는 사람이 판단하거나 조치할 사항

### 기본 구성

1. 보고 개요 또는 검토 배경
2. 현황
3. 주요 쟁점
4. 검토 내용 또는 대안
5. 검토 의견 또는 향후 조치

단순 현황보고라면 대안 비교를 억지로 넣지 않는다. 의사결정이 필요한 경우에는 대안별 장단점과 최종 검토 의견이 분명히 드러나도록 작성한다.

## 분량 조정

- A4 1쪽: 핵심 배경, 개요, 주요 내용, 요청 또는 향후 조치를 중심으로 통합한다.
- A4 2~3쪽: 기본 구성을 사용하고 필요한 표를 추가한다.
- 별도 분량이 없으면 사용자가 제공한 자료의 양과 문서 목적에 맞춰 지나치게 길지 않게 작성한다.
