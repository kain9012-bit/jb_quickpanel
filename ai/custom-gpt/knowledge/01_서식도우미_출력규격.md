# 서식도우미 출력 규격

이 문서는 생성형 AI의 최종 초안을 전북교육 한글 서식도우미가 안정적으로 변환하기 위한 필수 규격이다.

## 허용 태그

- `(문서제목)`
- `(제목)`
- `(소제목)`
- `(소소제목)`
- `(본문)`
- `(참고)`
- `(표시작)`
- `(표끝)`

괄호 안의 명칭을 바꾸거나 새로운 태그를 만들지 않는다.

## 태그별 표준 형식

```text
(문서제목) - 2026년 ○○ 사업 운영 계획(안)
(제목) 1. 추진 배경
(소제목) 가. 추진 방향
(소소제목) 1) 세부 추진 내용
(본문) - 핵심 내용을 개조식으로 작성
(참고) ※ 확인하거나 참고할 사항을 작성
```

최종 응답 자체에는 코드 블록 표시를 넣지 않는다. 위 코드는 규격 설명용 예시다.

## 번호와 기호

- 문서제목은 문서 첫 부분에 한 번만 둔다.
- 1단계 제목은 `1.`, `2.`, `3.` 순서로 작성한다.
- 2단계 제목은 각 1단계 제목 안에서 `가.`, `나.`, `다.` 순서로 작성한다.
- 3단계 제목은 각 2단계 제목 안에서 `1)`, `2)`, `3)` 순서로 작성한다.
- 본문은 `-`로 시작한다.
- 참고는 `※`로 시작한다.
- 최종 번호와 기호 모양은 서식도우미가 사용자 설정에 맞춰 다시 적용하므로 AI는 항상 위 표준 형식을 사용한다.

## 빈 줄

- 문서제목 위에는 빈 줄을 넣지 않는다.
- 문서제목과 첫 번째 제목 사이에는 빈 줄 한 줄을 둔다.
- 새로운 1단계 제목 위에는 빈 줄 한 줄을 둔다.
- 1단계 제목 바로 다음에 오는 2단계 제목 앞에는 빈 줄을 넣지 않는다.
- 2단계 제목 바로 다음에 오는 3단계 제목 앞에는 빈 줄을 넣지 않는다.
- 본문·참고·표 다음에 새로운 2단계 또는 3단계 제목이 오면 그 앞에 빈 줄 한 줄을 둔다.
- 표가 끝난 뒤에는 빈 줄 한 줄을 둔다.
- 연속된 본문 사이에는 불필요한 빈 줄을 넣지 않는다.

## 표

표는 다음 형식으로 작성한다.

```text
(표시작)
구분|주요 내용|일정
계획 수립|세부 추진계획 확정|2026. 3월
사업 운영|세부 사업 추진|2026. 4.~11.
(표끝)
```

표 작성 규칙은 다음과 같다.

- `(표시작)`과 `(표끝)`은 각각 한 줄에 단독으로 작성한다.
- 열은 `|` 문자로만 구분한다.
- 셀 앞뒤에 불필요한 공백을 넣지 않는다.
- 모든 행의 열 개수를 동일하게 유지한다.
- Markdown 구분선인 `|---|---|`을 작성하지 않는다.
- 표의 처음과 끝에 불필요한 `|`를 붙이지 않는다.
- 병합셀과 셀 안 줄바꿈은 사용하지 않는다.
- 셀 안의 문장은 짧게 작성한다.
- 표 안에 별도 태그나 주석을 넣지 않는다.
- 설명이나 참고사항은 표 밖에서 `(본문)` 또는 `(참고)`로 작성한다.

## 금지 형식

- `# 추진 배경` 같은 Markdown 제목
- `**중요**` 같은 Markdown 강조
- 결과 전체를 감싸는 코드 블록
- `•`, `▶` 등 임의의 본문 기호
- `(개요)`, `(표제목)` 등 정의되지 않은 태그
- HTML 표
- Markdown 표 구분선
