# 전북교육 보고서 작성 AI 설정 패키지

이 폴더는 전북교육 한글 서식도우미와 함께 사용하는 Custom GPT 시범판의 원본 설정을 관리한다.

## 구성

- `instructions.md`: Custom GPT의 지침 칸에 입력할 핵심 행동 규칙
- `knowledge/01_서식도우미_출력규격.md`: 태그, 번호, 빈 줄, 표 작성 규격
- `knowledge/02_공무원_보고서_작성원칙.md`: 문체, 사실성, 내용 구성 원칙
- `knowledge/03_기본문서유형.md`: 계획서, 결과보고서, 일반 보고서의 기본 설계도
- `knowledge/04_작성예시.md`: 서식도우미와 호환되는 작성 예시
- `evals/품질평가_사례.md`: 배포 전 반복 시험할 입력 사례와 평가 기준
- `validate_package.py`: 작성 예시와 현재 서식도우미 파서의 호환성 검사

## Custom GPT 설정 순서

1. GPT 이름과 설명을 입력한다.
2. `instructions.md`의 내용을 GPT 지침에 넣는다.
3. `knowledge` 폴더의 문서 4개를 지식 파일로 올린다.
4. 아래 대화 시작 문구를 등록한다.
5. `evals/품질평가_사례.md`의 사례로 출력 품질을 확인한다.

## 호환성 검사

프로젝트 루트에서 다음 명령을 실행한다.

```powershell
python ai/custom-gpt/validate_package.py
```

작성 예시의 태그, 문서제목 개수, 표 열 개수와 실제 자동 서식 파싱 결과를 검사한다.

## 권장 이름

전북교육 보고서 작성 도우미

## 권장 설명

공무원 보고서와 계획서 초안을 작성하고 전북교육 한글 서식도우미에서 바로 변환할 수 있는 형식으로 정리합니다.

## 권장 대화 시작 문구

- 사업 자료를 바탕으로 운영 계획서를 작성해 주세요.
- 추진 결과를 바탕으로 결과보고서를 작성해 주세요.
- 검토자료를 1쪽 보고서로 정리해 주세요.
- 기존 초안을 공무원 보고서 형식으로 다듬어 주세요.

## 운영 원칙

- 이 폴더의 문서를 원본으로 관리하고 GPT 편집 화면에서만 별도로 수정하지 않는다.
- 서식도우미의 태그나 표 규격이 변경되면 `01_서식도우미_출력규격.md`와 GPT 지침을 함께 갱신한다.
- 지식 파일에는 개인정보, 비공개 내부자료, 보안정보가 포함된 실제 문서를 올리지 않는다.
- 실제 우수 사례를 추가할 때는 기관명, 개인명, 연락처, 예산 세부정보 등 민감한 내용을 익명화한다.
