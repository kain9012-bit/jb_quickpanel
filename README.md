# JBEdu FORM (JB에듀 폼)

> 서식에 쓰던 시간을, 본연의 업무에.

**한글 문서와 K-에듀파인 기안창의 반복 편집을 줄이는 Windows용 업무 도구입니다.**

보고서의 제목과 본문에 서식을 입히고, 표를 다듬고, 셀마다 문자를 붙이고, 자간을 조정하는 작업을 문서 옆에서 실행합니다. 자주 쓰는 양식과 개인 설정을 모아 두고 다음 문서에서도 그대로 활용할 수 있습니다.

## 왜 만들었나요?

문서의 내용은 완성했는데, 제목 상자를 넣고 글꼴과 크기를 맞추고 표를 정리하는 데 다시 시간이 듭니다. 매번 같은 메뉴를 열고 같은 설정을 반복하는 일도 적지 않습니다.

JBEdu FORM은 이 반복을 줄이기 위해 시작했습니다. 한글을 대체하는 새로운 문서 작성기가 아니라, **지금 사용 중인 한글과 기안창 옆에서 필요한 작업을 돕는 도구**를 지향합니다.

- **내용에 집중**: 직접 작성하거나 생성형 AI로 준비한 초안에 문서 서식 적용
- **기존 환경 활용**: 한글 문서와 K-에듀파인 기안창에서 작업 이어가기
- **사용자 방식 존중**: 제목 양식, 글자 서식, 번호, 기호와 자주 쓰는 자료를 직접 설정
- **반복 작업 축소**: 표·셀·글자 편집을 선택 영역에 묶어서 실행
- **현장 의견 반영**: 실제 사용 과정에서 발견한 불편과 오류를 바탕으로 개선

## 주요 기능

### 초안을 보고서로, 서식 자동 지정

한글에서 초안을 블록 지정하고 **전체 서식 자동 지정하기**를 누르면 문서 구조를 분석해 제목·본문·참고·표에 설정한 서식을 적용합니다. 별도 AI API 키 없이 프로그램 내부 규칙으로 처리합니다.

- 문서제목, 1·2·3단계 제목, 본문, 참고의 글꼴·크기·굵기 설정
- 제목 번호의 숫자·한글·로마자 형식과 본문 앞 기호 지정
- 기존 보고서에서 쓰던 제목 양식을 등록해 재사용
- 자동 서식 설정을 최대 10개까지 저장하고 상황에 따라 선택
- 텍스트 표 인식과 기존 한글 표의 구조를 유지한 서식 적용
- 문서 전체 대신 선택한 문장에 제목·본문 등 개별 서식 적용

### 표·셀·글자, 반복 편집 줄이기

| 작업 | 할 수 있는 일 |
| --- | --- |
| 표 작업 | 테두리·배경색 정리, 행 높이·열 너비 맞추기, 제목 셀 설정, 표 그리기, 글자처럼 취급·해제 |
| 셀 정리 | 앞뒤 공백 제거, 셀 내용 찾아바꾸기, 셀마다 앞·뒤 문자 붙이기, 엑셀 붙여넣기 흔적 정리 |
| 여러 셀에 그림 넣기 | 파일명 순서로 그림 삽입, 셀 안·너비·크기에 맞추기, 기존 그림 다시 맞추기 |
| 글자 작업 | 글꼴·크기·색 변경, 위첨자·아래첨자, 자간 정리와 초기화 |

자간 정리는 실제 줄 배치를 확인하며 필요한 범위만 조정합니다. 문장 내용과 글꼴을 바꾸지 않고 번호·앞 기호·괄호 항목명은 유지하며, 해결되지 않는 조정은 원래 자간으로 되돌립니다.

### 자주 쓰는 자료를 내 도구함에

- **서식**: 한글에서 블록 지정한 내용을 내 서식으로 등록
- **양식**: 보고서·계획서 양식 삽입 또는 새 문서로 열기
- **문자표**: 특수문자 삽입, 내 문자표 추가, 묶음 순서 변경, 글자 겹치기
- **심볼**: 교육비전·슬로건·이미지 삽입과 내 심볼 등록
- **편집용지**: 기본 보고서 세로·가로, 사용자 여백·방향 설정, 문서 전체·현재 페이지만 적용
- **즐겨찾기**: 자주 쓰는 서식·양식·심볼·편집용지를 목록 앞에 모으기

### 한글과 기안창, 모드만 바꿔서

상단의 적용 대상 버튼으로 **이미 열려 있는 작업창**을 선택합니다. 모드 전환은 문서나 기안창을 새로 여는 기능이 아닙니다.

| 구분 | 일반 한글 | K-에듀파인 기안창 |
| --- | --- | --- |
| 주요 용도 | 보고서·계획서 작성과 문서 편집 | 공문 본문 작성과 편집 |
| 서식 탭 | HWP 서식 조각 삽입, 자동·개별 서식 적용 | HWP 서식 조각 삽입 |
| 양식 탭 | HWP·HWPX 양식 삽입 또는 새 문서 열기 | 내부결재 3종·발송용 8종의 기안문 본문 예시 삽입 |
| 내 자료 | 내 서식·양식·문자표·심볼·편집용지 | 내 기안문 양식을 본문 텍스트로 등록 |
| 모드 전용 기능 | 자간 정리, 여러 셀에 그림 넣기, 편집용지, 한글과 나란히 배치 등 | 기안창용 양식 분류와 본문 삽입 |

기안창에서는 해당 환경에서 사용할 수 있는 기능만 표시합니다. 기안문 양식은 제목을 따로 입력하고 본문에 삽입하며, 사용 목적에 맞게 내용을 수정해 사용합니다.

### 내 설정을 다음 PC에서도

- 자동 서식 설정과 등록 자료를 재실행·업데이트 후에도 유지
- 설정·내 자료를 하나의 백업 파일로 저장하고 다른 PC에서 복원
- 복원 전 현재 상태 자동 백업
- 처음 사용 튜토리얼, HTML 사용자 매뉴얼, 업데이트 내역 제공
- 일반 한글과 도우미 창을 버튼 한 번으로 나란히 배치

## 설치와 실행

### 사용 환경

- Windows 64비트 환경
- 설치형 한컴 한글
- K-에듀파인 사용 시 한글 COM 편집 컨트롤이 제공되는 기안창 환경
- Tauri 화면 실행을 위한 Microsoft Edge WebView2 런타임

**설치본 사용자는 Python·Node.js·Rust를 별도로 설치할 필요가 없습니다.** 한글 자동화에 필요한 Python 백엔드는 설치파일에 포함됩니다. 웹 한글, macOS, Linux용 프로그램은 아닙니다.

### 내려받기

- [전북교육청 데이터 도구실](https://www.jbe.go.kr/board/list.jbe?boardId=BBS_0000649&menuCd=DOM_000000106011002001&contentsSid=3256&cpath=): 교육청 배포 도구에서 JBEdu FORM 확인
- [GitHub Releases](https://github.com/kain9012-bit/jb_quickpanel/releases): 공개된 설치파일과 배포 이력 확인

교육청 홈페이지 경로: **행정정보 > 교육데이터 허브 > 데이터 도구실 > 교육청 배포 도구**

GitHub의 `Code > Download ZIP`은 개발 소스입니다. 일반 사용자는 설치파일을 내려받아 실행합니다. 저장소의 소스와 이미 게시된 설치본의 버전은 다를 수 있으므로 배포본의 버전과 변경 기록을 확인하세요.

## 처음 사용하기

1. 한글 문서 또는 K-에듀파인 기안창을 엽니다.
2. JBEdu FORM을 실행하고 상단에서 적용 대상을 선택합니다.
3. 대상 문서에 커서를 놓거나, 적용할 텍스트·셀을 선택합니다.
4. 필요한 버튼이나 카드를 누릅니다.
5. 문서의 적용 결과와 도우미 하단 상태 메시지를 확인합니다.

보고서 자동 서식은 **초안 블록 지정 → 사용할 설정 선택 → 전체 서식 자동 지정하기** 순서로 사용합니다. 여러 한글 창이 열려 있다면 작업할 문서를 먼저 클릭해 주세요.

자세한 사용법은 앱 상단의 **매뉴얼**, 설정의 **사용자 매뉴얼** 또는 **튜토리얼 다시 보기**에서 확인할 수 있습니다.

## 알아두면 좋은 점

- **결과는 한글 문서로 유지**: 적용 후에도 한글에서 직접 수정·저장할 수 있습니다.
- **자동 서식은 문서 편집 기능**: 내용의 사실관계를 검증하거나 보고서 내용을 대신 작성하지는 않습니다.
- **문서 구조에 따른 차이**: 복잡한 병합 표·개체·구역 구성은 결과를 확인해 주세요. 현재 페이지의 용지 방향을 바꾸면 내용이 다음 페이지로 이어질 수 있습니다.
- **원문 보호**: 자동 서식은 새 결과를 준비·확인한 뒤 원문을 교체하며, 그림·도형 등 안전하게 처리하기 어려운 선택은 변경 전에 중단합니다. 중요한 문서는 작업 전 저장해 두세요.
- **연결 문제**: 문서가 아닌 다른 창에 연결된 것 같다면 대상 문서를 클릭하고 상단 새로고침으로 다시 연결합니다.

## 설정과 자료 저장

설정과 사용자 등록 자료는 설치 폴더와 분리된 `%APPDATA%\JbHwpHelper`에 저장합니다. 프로그램 이름이나 설치본이 바뀌어도 기존 자료를 이어서 사용하기 위한 위치입니다.

PC 교체·인사이동 전에는 **설정 > 설정·내 자료 백업**에서 백업 파일을 만들고, 새 PC에서 복원합니다. 작업 중인 한글 문서 자체는 이 백업에 포함되지 않으므로 별도로 보관하세요.

핵심 문서 편집은 PC의 한글 COM 자동화로 수행합니다. 업데이트 확인·설치파일 다운로드에는 네트워크를 사용합니다. 공개 이슈나 화면 캡처에는 개인정보와 업무 문서 원문을 포함하지 않도록 주의해 주세요.

## 개발자를 위한 안내

현재 소스 기준: **v.0.0.7**. 초기 `전북교육 한글 서식도우미`의 기능을 이어받아 Tauri 설치형 앱으로 개발하고 있습니다.

화면은 **React + TypeScript**, 데스크톱 기능은 **Tauri + Rust**, 문서 자동화는 **Python + pywin32**가 담당합니다. Tauri는 UI만 표시하는 웹페이지가 아니라 창·트레이·단축키·업데이트와 Python 백엔드 실행을 함께 관리합니다.

### 소스 실행

준비: Python 3.12, Node.js LTS, pnpm, Rust MSVC 툴체인과 Windows C++ 빌드 도구. pnpm 버전은 [package.json](tauri-prototype/package.json)의 `packageManager`를 따릅니다.

```powershell
git clone https://github.com/kain9012-bit/jb_quickpanel.git
cd jb_quickpanel
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
cd tauri-prototype
pnpm install --frozen-lockfile
pnpm tauri:dev
```

개발 실행은 저장소의 `.venv\Scripts\python.exe`를 우선 사용합니다. 실제 문서 기능 확인에는 실행 중인 한글 또는 기안창이 필요합니다. 루트의 `app.py`는 이전 Tk 기반 진입점이며 현재 Tauri 화면 실행 경로는 아닙니다.

### 검사와 빌드

```powershell
# 저장소 루트에서 실행
.\.venv\Scripts\python.exe -m pip install pytest
$env:PYTHONPATH = "$PWD;$PWD\tauri-prototype"
.\.venv\Scripts\python.exe -m pytest --import-mode=importlib -q tests tauri-prototype/backend
cd tauri-prototype
pnpm build
pnpm manual:check
cargo check --manifest-path src-tauri/Cargo.toml
```

설치본 생성과 서명·업데이트 배포 절차는 [개발 안내](tauri-prototype/README.md)와 [자동 업데이트 안내](tauri-prototype/AUTO_UPDATE.md)를 참고합니다. 서명 개인키는 저장소에 포함하지 않습니다. 일반 소스 푸시만으로 설치본이 새로 배포되지는 않습니다.

### 저장소 구조

```text
tauri-prototype/
  src/                   React 화면
  src-tauri/             Tauri 창·트레이·단축키·업데이트
  backend/               Python 명령 서버와 Tauri 전용 연결
src/jb_quickpanel/
  bridges/               일반 한글·기안창 COM 연결
  features/              서식·표·셀·글자·편집용지 자동화
  services/              설정·사용자 자료·백업 관리
config/                  기본 자료 목록과 기안문 본문 예시
blocks_hwp/              서식 조각
forms_hwp/               일반 한글 양식
symbols/                 비전·슬로건·이미지
매뉴얼/                  설명 원본과 HTML·PDF 생성 도구
tests/                   회귀 테스트
docs/media/              소개영상과 미리보기
```

기능을 바꾸면 실제 사용 흐름과 [사용자 매뉴얼 원본](매뉴얼/원본/content.json)을 함께 갱신합니다. [매뉴얼 생성 절차](매뉴얼/README.md)는 설명 검토 기록을 확인하고 현재 UI에서 화면과 HTML·PDF를 생성합니다.

## 의견과 개선 제안

[GitHub Issues](https://github.com/kain9012-bit/jb_quickpanel/issues)에 사용 모드, 수행한 작업, 기대한 결과와 실제 결과를 남겨 주세요. 한글 버전과 오류 메시지가 있으면 원인 확인에 도움이 됩니다. 재현 자료는 개인정보를 제거한 예시 문서로 부탁드립니다.

더 많은 기능을 넣는 것만큼 **이미 쓰는 기능이 예상대로 작동하는 것**을 중요하게 생각합니다. 현장에서 사용하는 분들의 피드백을 바탕으로 계속 다듬어 가겠습니다.
