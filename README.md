# 전북교육 한글 서식도우미

전북교육청 보고서, 계획서, 기안문 작성에 자주 쓰는 한글 서식 작업을 빠르게 적용하기 위한 Windows용 보조 도구입니다.

## 현재 버전

- 최신 소스 진입 파일: `app(v3.4).py`
- 창 제목 표시: `전북교육 한글 서식도우미 v3.4`
- 배포 EXE 이름: `전북교육_한글_서식도우미_v3.4.exe`
- Windows 검색 이름: `전북교육 한글 서식도우미 (v3.4)`
- 단일 EXE 실행 시 초기 준비 상태를 보여주는 스플래시 화면 표시
- 최신 배포 파일 위치: `exe버전관리`
- 업데이트 내역: `CHANGELOG.md`

## 빠른 실행

프로젝트 폴더에서 실행합니다.

```powershell
cd "C:\work\jb_quickpanel"
python "app(v3.4).py"
```

한글 문서에 적용하는 기능은 한글을 먼저 실행하고 문서를 열어둔 상태에서 사용합니다.

## 주요 기능

- 기본 제공 서식·양식·심볼·편집용지 빠른 삽입
- 내 서식·양식·편집용지 등록, 이름 변경, 삭제
  - 내 서식은 내용 중심, 내 양식은 첫 페이지 상단 기준 2.5배 확대 미리보기 자동 생성
  - 사용자 관리에서 미리보기 자동 재생성·이미지 교체·삭제
  - 편집용지 카드에 여백값 미리보기를 자동 표시하고 수정과 동시에 갱신
- 내 문자표 그룹 추가·수정·삭제 및 기본 문자표보다 위에 우선 표시
- 문자표의 `괄호` 그룹에서 `「」`, `『』`, `〈〉`, `《》`, `【】`, `〔〕`, `〖〗` 빠른 삽입
- 보고서/계획서용 서식 자동 지정
  - 기존 태그가 있으면 태그 기반 방식을 그대로 사용
  - 태그가 없으면 선택 영역 안의 번호·기호·내용 반복 체계를 분석해 문서제목·제목·소제목·소소제목·본문·참고 서식 적용
  - 내부 가상 태그에 따라 번호가 없는 제목 계층에는 `1.`, `가.`, `1)`을, 본문·참고에는 `- `와 `※ `를 자동 보충하고 기존 기호는 유지
  - 탭 구분 표와 Markdown `|` 표를 자동으로 한글 표로 변환
  - 선택 영역에 이미 들어 있는 한글 표는 행·열 구조를 유지하면서 표 서식 적용
- 표 선, 표 배경 등 표 작업 자동화
- 선택한 표 셀 범위에 여러 그림을 파일명 순서대로 자동 삽입
  - 셀 안에 맞춤, 셀 너비에 맞춤, 셀 크기에 맞춤 지원
  - 셀 크기를 바꾼 뒤 기존 그림 다시 맞춤
- 한글 표 셀 범위 정리
  - 불필요한 앞뒤 공백 제거
  - 찾아바꾸기
  - 앞/뒤 문자 추가
  - 엑셀 붙여넣기 공백·배경색 정리
- 글자 작업
  - 글꼴, 크기, 색상 변경
  - 줄 단위 자간 정리
  - 자간 초기화
- 일반 한글 문서와 K-에듀파인 기안창 모드 구분
- 우측 상단 `설정` 버튼과 별도 설정 창
  - 시작 위치, 마지막 창 위치 기억
  - 시작 시 적용 대상 지정
  - 처음 사용 튜토리얼과 다시 보기
  - 시작 시 새 버전 확인 및 수동 확인
  - README, 설정 폴더, 오류 기록, 변경 기록 열기
  - 닫기 시 트레이 최소화
  - Windows 시작 시 자동 실행
  - Windows 시작 시 트레이로 시작
  - 시작 메뉴 자동 등록
  - 트레이 상태에서도 작동하는 사용자 지정 전역 단축키

## 사용 전 준비

- 일반 한글 문서에 적용할 때는 한글을 먼저 실행합니다.
- K-에듀파인 기안창에 적용할 때는 기안창을 먼저 열고 본문 입력 영역에 커서를 둡니다.
- `항상 위로 표시`를 켜면 한글 위에 도구 창을 띄운 채 작업할 수 있습니다.
- 항상 위 상태에서는 버튼·탭 클릭이 한글 포커스를 유지하며, 셀 정리 입력칸처럼 키보드 입력이 필요한 곳을 클릭할 때만 서식도우미가 활성화됩니다.
- 소스 실행 기준으로 `vendor/pywin32` 폴더가 있으면 pywin32를 별도 설치하지 않아도 됩니다.

## 주요 사용법

### 서식/양식/편집용지

- `서식 자동 지정하기`, `중지`, `프롬프트 복사`는 서식 탭 맨 위에 있습니다.
- 보고서나 계획서 전체를 한글에서 블록 지정한 뒤 `서식 자동 지정하기`를 누릅니다.
- 태그가 하나라도 있으면 기존 태그 방식만 실행하고, 태그가 전혀 없을 때만 문서 내부 규칙 분석을 실행합니다.
- 문서제목은 선택 영역의 첫 번째 유효 문단에서만 판단합니다.
- 화면 하단 상태 표시줄에서 현재 작업과 완료 결과를 확인할 수 있습니다.

- 서식 또는 양식 카드를 누르면 현재 한글 커서 위치에 해당 조각 파일을 삽입합니다.
- 편집용지 탭은 기본 보고서 편집용지 같은 페이지 설정을 빠르게 적용합니다.
- K-에듀파인 기안창 모드에서는 지원 가능한 카드만 표시됩니다.

### 표 작업

- `내부 세로선 없애기`, `내부 가로선 없애기`는 선택한 셀 블록의 안쪽 구분선만 없애고 바깥선은 유지합니다.
- `행 높이 같게`, `열 너비 같게`는 선택한 직사각형 셀 블록을 균등하게 정리합니다.
- `한 줄로 입력 설정·해제`는 선택 셀에서 내용의 자동 줄바꿈 여부를 바꿉니다.
- `제목 셀 설정·해제`는 선택 셀을 표의 제목 셀로 지정하거나 해제합니다.
- 균등 배치는 불연속 선택이나 직사각형이 아닌 셀 블록에는 적용되지 않습니다.

### 셀 정리

1. 일반 한글 모드에서 어느 탭이 열려 있든 한글 표의 적용할 셀 범위를 마우스로 드래그합니다.
2. `편집도구 > 셀 정리` 탭을 엽니다.
3. 기억된 `선택됨` 범위와 행·열 수를 확인한 뒤 필요한 버튼을 누릅니다.

셀 범위가 선택되기 전에는 실행 버튼이 비활성화되고, 어느 탭에서든 선택이 끝나면 범위를 기억해 자동으로 활성화합니다.

지원 작업:

- 불필요한 앞뒤 공백 제거
  - 셀 안의 정상적인 띄어쓰기는 유지합니다.
- 찾아바꾸기
- 셀 내용 앞/뒤에 같은 문자 추가
- 엑셀 붙여넣기 흔적 정리
  - 셀 앞뒤의 불필요한 공백과 문단 배경색을 함께 정리합니다.

작업이 끝나면 변경된 셀 수가 선택 범위 영역과 화면 하단 상태표시줄에 표시됩니다. 병합 셀이 포함된 범위는 작업이 중단될 수 있으며, 이 경우 병합을 해제하거나 범위를 나눠서 처리합니다.

### 셀에 그림 넣기

1. 일반 한글 모드에서 그림을 넣을 빈 셀 범위를 마우스로 드래그합니다.
2. `편집도구 > 표 작업` 탭 맨 아래에서 기록된 셀 범위를 확인합니다.
3. 그림 크기 방식을 선택합니다.
4. `셀에 그림 넣기`를 누르고 그림 파일을 여러 개 선택합니다.

그림은 파일명 순서대로 왼쪽 위 셀부터 오른쪽 아래 셀까지 들어갑니다. 기본값인 `셀 안에 맞춤`은 셀 크기를 유지하면서 원본 비율대로 그림 전체를 넣고, `셀 너비에 맞춤`은 열 너비를 유지하면서 원본 비율에 따라 행 높이를 늘립니다. `셀 크기에 맞춤`은 원본 비율과 관계없이 현재 셀의 가로·세로 크기에 맞춥니다.

그림을 넣은 뒤 셀 크기를 변경했다면 같은 셀 범위와 크기 방식을 선택하고 `기존 그림 다시 맞춤`을 누릅니다. 그림이 없는 셀은 건너뛰며, 한 셀에 그림이 여러 개 있으면 임의로 변경하지 않고 상태표시줄에 건너뛴 셀 수를 표시합니다.

그림보다 셀이 많으면 필요한 셀까지만 사용하고, 그림이 더 많거나 내용이 있는 셀이 포함되면 문서를 변경하지 않고 중단합니다. 병합 셀이 포함된 범위와 K-에듀파인 기안창 모드에서는 사용할 수 없습니다.

### 자간 정리

- 위치: `편집도구 > 글자 작업`
- `자간 정리 1단계`: 자간 조정 명령 3회 적용
- `자간 정리 2단계`: 자간 조정 명령 5회 적용
- `자간 초기화`: 블록 지정 영역의 자간을 0으로 초기화

일반 텍스트는 블록 지정한 영역을 기준으로 처리합니다. 표 안에서는 셀 범위를 드래그해 기록한 뒤 자간 정리 버튼을 사용할 수 있습니다.

K-에듀파인 기안창 모드에서는 자간 정리 박스가 숨겨집니다.

## 내 서식·양식·편집용지 등록

### 내 서식과 내 양식

- `서식` 탭 아래의 `내 서식 추가`, `양식` 탭 아래의 `내 양식 추가`를 누릅니다.
- 한글에서 선택한 현재 블록을 등록하거나 기존 HWP·HWPX 파일을 선택할 수 있습니다.
- 서식은 현재 블록 등록, 양식은 한글 파일 등록을 기본 선택으로 안내합니다.
- 등록할 때 파일을 사용자 자료 폴더로 복사하므로 원본을 옮기거나 삭제해도 등록 항목은 유지됩니다.
- 내 서식 미리보기는 내용 중심으로 표시하고, 내 양식 미리보기는 첫 페이지 상단을 2.5배 확대해 표시합니다.
- 사용자 관리에서 미리보기를 자동으로 다시 만들거나 원하는 이미지로 교체·삭제할 수 있습니다.
- 각 탭의 `사용자 서식 관리`, `사용자 양식 관리`에서 이름을 바꾸거나 삭제할 수 있습니다.
- 사용자 항목 등록과 삽입은 일반 한글 모드에서 사용합니다.

### 내 편집용지

- `편집용지` 탭 아래의 `내 편집용지 추가`를 누릅니다.
- 한글의 용지 여백 창과 비슷한 배치에서 위쪽, 아래쪽, 왼쪽, 오른쪽, 머리말, 꼬리말, 제본 여백을 입력합니다.
- 모든 값은 mm 단위이며 0.1mm씩 조정할 수 있습니다.
- 저장한 카드를 누르면 현재 구역의 여백만 적용하며 용지 크기와 방향은 바꾸지 않습니다.
- `사용자 편집용지 관리`에서 이름과 여백을 수정하거나 항목을 삭제할 수 있습니다.
- 카드에는 위·아래·왼쪽·오른쪽·머리말·꼬리말 여백값이 자동으로 표시되며, 값을 수정하면 함께 갱신됩니다.

사용자 자료는 `%APPDATA%\JbHwpHelper\user_content`에 저장되어 새 버전의 EXE로 교체해도 유지됩니다.

## 전역 단축키

- `설정 > 전역 단축키 > 단축키 설정`에서 원하는 기능을 검색하고 단축키를 지정합니다.
- 기능을 더블클릭하거나 선택한 뒤 `단축키 지정`을 누르고 `Ctrl`, `Alt`, `Shift`, `Win` 중 하나 이상과 문자·숫자·기능키를 함께 누릅니다.
- 같은 조합을 다른 기능에 지정하면 기존 지정을 새 기능으로 옮길지 확인합니다.
- 다른 프로그램이나 Windows가 이미 사용하는 조합은 저장 후 `충돌`로 표시되며 등록되지 않습니다.
- 서식도우미가 화면에 있거나 트레이에 숨겨져 있어도 프로그램이 실행 중이면 사용할 수 있습니다.
- 문서 작업 기능은 한글 또는 K-에듀파인 기안창이 활성화된 상태에서만 실행하며, 설정한 `적용 대상`을 기준으로 동작합니다.
- `서식도우미 열기/숨기기`는 문서 활성화 여부와 관계없이 사용할 수 있습니다.
- 단축키 관리창을 여는 동안에는 키 입력이 문서 기능으로 실행되지 않도록 전역 단축키가 잠시 중지됩니다.

## 설정과 처음 사용 안내

- 처음 실행하면 7단계 사용 안내가 자동으로 열립니다.
- 설정 창은 일반 화면에서 모든 항목을 한 번에 볼 수 있는 높이로 열리며, 화면이 작거나 창 높이를 줄이면 세로 스크롤을 사용할 수 있습니다.
- 각 화면의 세로 스크롤바는 내용이 표시 영역을 넘을 때만 자동으로 나타납니다.
- 안내를 닫거나 완료한 뒤에도 `설정 > 튜토리얼 다시 보기`에서 다시 확인할 수 있습니다.
- `Windows 시작 시 트레이로 시작`은 `닫기 시 트레이로 최소화`와 `Windows 시작 시 자동 실행`을 모두 켠 경우에만 사용할 수 있습니다.
- Windows 자동 실행을 켠 상태에서 새 버전을 실행하면 자동 실행 경로도 현재 실행 파일로 갱신됩니다.
- 시작 메뉴에는 `전북교육 한글 서식도우미 (v3.4)`으로 등록됩니다. 새 버전이나 다른 위치의 파일을 실행하면 현재 실행 파일을 가리키도록 갱신하고 같은 앱의 구버전 바로가기는 정리합니다.
- 업데이트 확인에 실패해도 프로그램 실행과 한글 문서 작업은 계속할 수 있습니다.
- 업데이트 안내 연결 정보는 아직 비워 두었으며, 고유번호를 설정하기 전까지는 설정 창에 `업데이트 정보 미설정`으로 표시됩니다.

## 수정 원칙

- 새 기능은 가능한 한 `features`에 먼저 작성하고, UI는 버튼 연결만 담당하게 합니다.
- 일반 한글 조작은 `bridges/hwp_bridge.py`, 기안창 조작은 `bridges/wxs_bridge.py`에 둡니다.
- 화면 배치나 탭 표시 정책은 `ui/app_window.py`에서만 다룹니다.
- 버튼 이름, 모드별 표시 정책, 글꼴/자간 버튼 정의는 `features/registry.py`에 둡니다.
- 설정 저장과 오류 기록은 `services/app_config.py`에 두고, 사용자 등록 자료는 `services/user_content.py`에서 관리합니다.
- 리소스 경로, 클립보드, 공통 유틸은 `core/runtime.py`에 둡니다.
- 기능을 바꾸면 `CHANGELOG.md`에 버전별 변경 내용을 남깁니다.

## 개발 실행

개발 중에는 프로젝트 폴더에서 아래 파일을 실행합니다.

```powershell
python "app(v3.4).py"
```

한글 자동화 기능은 Windows에서 한글이 실행 중일 때 동작합니다. 일부 기능은 `pywin32`, `Pillow`, `tkinter`가 필요합니다.

## 빌드

배포용 exe는 `build_release.ps1`을 사용하는 것을 권장합니다.

```powershell
.\build_release.ps1
```

직접 빌드할 때는 PyInstaller spec 파일을 기준으로 만듭니다.

```powershell
python -m PyInstaller --clean --noconfirm "전북교육_한글_서식도우미_v3.4.spec"
```

빌드 후 확인할 항목:

- exe가 바로 종료되지 않는지 확인
- `서식`, `편집도구`, `문자표`, `심볼`, `양식`, `편집용지`, `설정` 탭이 정상 표시되는지 확인
- 일반 한글 모드와 K-에듀파인 기안창 모드의 표시 기능이 구분되는지 확인
- `exe버전관리` 폴더에 exe와 zip을 보관
- `CHANGELOG.md` 갱신
