# Tauri 전환판 변경 기록

## v4.0

- Tauri + React 전환판을 정식 v4.0으로 확정
- 사용자 화면, 창 제목, 제품명과 설치파일 이름을 `v4.0`으로 통일
- Python COM 백엔드를 PyInstaller sidecar로 패키징해 Python 미설치 PC 지원
- 기본 서식·양식·편집용지·표 미리보기·심볼 자료를 sidecar에 포함
- 세로형 심볼 미리보기 비율 오류와 흰색 심볼 식별 문제 수정
- 심볼 이미지 그룹을 최신 PNG 54개 구성으로 교체
- NSIS 설치형 EXE와 압축파일을 만드는 `build_v4.ps1` 추가
## v4.0.0-alpha.1

- 기존 v3.4 기능을 Tauri + React 화면으로 전면 이식
- Python COM 서버를 앱 실행 중 유지하는 sidecar 구조 적용
- 한글 선택 범위를 보존하는 비활성 팔레트 창 처리
- 태그·무태그 서식 자동 지정과 표 다음 본문 위치 복귀 오류 수정
- 서식·표·셀·글자·문자표·심볼·양식·편집용지 전체 UI 구현
- 사용자 항목 등록·관리 및 자동/직접 미리보기 구현
- 전역 단축키, 트레이, 중복 실행 방지, Windows 통합 설정 구현
- 시작 위치·위치 기억·업데이트 안내·튜토리얼·설정 초기화 구현
- 개발 실행에서는 실제 시작 메뉴를 변경하지 않는 보호 처리 추가
