# JBEdu FORM (JB에듀 폼) 변경 기록

## v.0.0.7

- 앞뒤 공백 정리에서 셀 전체를 다시 입력하지 않고 삭제할 공백만 확인 후 제거
- 셀마다 문자 붙이기를 셀의 시작·끝에만 삽입하도록 변경
- 기존 글자의 부분 굵기·글자색·줄바꿈·탭·이모지 유지
- 빈 셀에 문자 붙이기 동작 유지, 셀 선택 방식·찾아바꾸기·엑셀 흔적 정리 변경 없음

## v.0.0.6

- 자동 서식에서 반복 기호가 포함된 기관명, 날짜, 음수, 파일명이 잘못 변경되는 경우 수정
- 표 안의 빈 값 표시(-)와 이스케이프한 세로선(\|), 파일 경로 보존
- 새 결과 작성·확인 후 원문 교체, 실패·중지 시 새 결과만 정리하도록 개선
- 그림·도형이 포함되거나 선택 범위 구조를 확인할 수 없으면 원문 변경 전 중단
- 작업 중 한글 문서가 바뀐 경우 다른 문서에 원문을 덮어쓰지 않도록 확인 추가
- 기존 자동 서식 설정·수동 서식·문자표·셀 편집 방식 유지

## v.0.0.5

- 마침표 없는 숫자 제목(예: `1 추진 배경`)을 기존 숫자 제목과 같은 단계로 인식
- 기존 제목 번호를 내용과 분리하여 번호 중복과 중간 제목 누락 수정
- 세로선 하나로 구분한 2열 텍스트 표도 연속 행을 확인하여 표로 변환
- 제목·본문·참고·표 안의 짝이 맞는 마크다운 강조 표시(`**`, `__`) 제거
- 사용자 자동 서식 설정과 본문 앞 기호 유지, 문자·서식 삽입 및 COM 처리 변경 없음

## v.0.0.4

- 기본 보고서 편집용지를 A4 세로·가로 각 1개씩 제공, 기존 세로 카드 즐겨찾기 유지
- 편집용지 탭에 문서 전체·현재 페이지만 적용 범위 선택 추가
- 현재 페이지 앞뒤의 필요한 경계만 COM 구역 나누기로 분리, 기존 구역 경계 재사용
- 현재 페이지 적용 후 내용이 넘치면 같은 구역에서 다음 페이지로 이어지며 앞뒤 구역의 용지 설정 유지
- 내 편집용지 추가·수정에서 세로·가로 방향 저장 및 미리보기 반영
- 기존 사용자 편집용지와 즐겨찾기·백업 호환 유지, 자동 서식의 기존 편집용지 처리 변경 없음

## v.0.0.3

- 새로 추가한 내 문자표를 맨 위에 배치하고 기존 문자표 묶음의 상대 순서 유지
- 순서 변경에 맨 위로 이동·맨 아래로 이동 버튼 추가, 기존 한 칸 이동 유지
- 문자표 수정 시에는 기존 위치 유지하며 저장한 순서는 재실행·업데이트·백업 복원 후에도 유지
- 내 문자표 삭제 확인을 프로그램 내 창으로 변경: 내 문자표 삭제 / 취소·삭제
- 저장·삭제 실패 시 기존 자료와 표시 순서를 유지하고 삭제 확인창에서 오류 표시

## v.0.0.2

- 자간 정리: 실제 줄 배치를 확인하고 단어 중간 줄넘김·짧은 마지막 줄에 필요한 최소 자간 적용
- 1단계는 최대 ±3%, 2단계는 최대 ±5% 범위에서 조정하며 이미 범위를 벗어난 사용자 자간은 더 같은 방향으로 변경하지 않음
- 해결되지 않는 조정은 원래 자간으로 복원하고 실패·중단 시 이번 작업의 자간 변경 복원
- 번호·앞 기호·괄호 항목명과 글꼴·장평·문장 내용 유지
- 표 안 일부 텍스트를 블록 지정하면 셀 전체로 확대하지 않고 선택한 글자만 처리
- 기존 두 버튼·선택 방식 유지, 클립보드·파일 저장·문서 변환 없이 COM으로 처리

## v.0.0.1

- 정식 배포 이름을 JBEdu FORM (JB에듀 폼)으로 변경하고 버전을 0.0.1부터 시작
- 프로그램 제목·설치파일·바로가기·매뉴얼의 이름 통일
- 기존 기능과 설정·사용자 자료·백업 호환 유지
- 이전 시험판 업데이트와 정식 배포 업데이트 정보 분리
- 튜토리얼을 현재 화면과 기능에 맞춰 갱신: 나란히 배치·매뉴얼·자동 서식 설정·즐겨찾기·글자 겹치기·문자표 순서·백업·업데이트 안내
- 일반 한글과 기안창 모드별 사용 가능한 기능만 안내

## v.4.2.5

- 일반 한글 모드 상단에 한글과 나란히 배치 버튼 추가
- 누를 때마다 현재 연결된 한글은 왼쪽, 서식도우미는 오른쪽에 다시 정렬
- 연결된 한글이 있는 모니터의 배율과 작업표시줄을 제외한 작업 영역 사용
- 화면 공간 부족 시 이동 전 안내하고 배치 실패 시 원래 배치 복원 시도
- 나란히 배치 중 임시 위치가 마지막 창 위치 기억 설정을 덮어쓰지 않도록 처리
- 기본 실행 방식 유지, K-에듀파인 기안창 모드에는 버튼 미표시

## v.4.2.4

- 편집도구의 글자 작업에 위첨자·아래첨자·첨자 해제 버튼 추가
- 첨자 해제는 첨자만 풀고 글꼴·크기·굵기 등 기존 글자 서식 유지
- 문자표에 네모문자 숫자(1~20) 추가
- 문자표 상단에 글자 겹치기 추가: 글자 입력 후 원·네모 모양으로 삽입
- 문자표 상단 순서 변경 버튼 추가: 기본 분류·내 문자표 묶음을 위·아래로 이동하고 순서 저장
- 문자표 순서는 재실행·업데이트·설정 백업 복원 후에도 유지
- 일반 한글과 K-에듀파인 기안창의 기존 COM 연결 사용

## v.4.2.3

- 표 작업 마지막에 글자처럼 취급·글자처럼 취급 해제 버튼 추가
- 선택한 표·그림 또는 커서가 들어 있는 표에만 적용하고 변경 결과 확인
- 표 그리기·글자처럼 취급·해제 아이콘을 표 그림 스타일로 통일하고 표 작업 카드 높이를 기존의 3/4로 축소
- 아이콘 크기는 유지하고 이미지의 빈 테두리와 카드 위아래 여백만 축소

## v.4.2.2

- 편집도구의 표 작업에 표 그리기 버튼 추가
- 일반 한글·K-에듀파인 기안창의 기존 COM 연결로 표 그리기 모드 시작
- 표 그리기 버튼에서만 문서 입력 창으로 포커스 전달

## v.4.2.1

- 서식·일반 한글 양식·기안창 양식·심볼·편집용지 카드 오른쪽 위에 즐겨찾기 별 추가
- 즐겨찾기는 각 탭과 분류의 앞에 등록 순서대로 표시하고 새 항목은 즐겨찾기 묶음 뒤에 추가
- 해제하면 원래 순서로 복귀하며 기존의 최신 등록 우선 순서는 최초 등록 순서로 한 번 이전
- 즐겨찾기를 기존 사용자 설정에 저장하고 설정 백업·복원에 포함
- 심볼의 비전·슬로건·이미지 분류 탭을 편집도구와 동일한 밑줄형 디자인으로 통일

## v.4.2.0

- K-에듀파인 기안문 본문 예시 11종을 내부결재 3종·발송용 8종으로 분류
- 기안창 양식은 HWP 파일 대신 본문 텍스트를 직접 삽입하고 사용자 양식도 텍스트로 등록·수정
- 서식 탭은 일반 한글과 기안창 모두 HWP만 삽입하며 내 서식은 블록 지정으로 추가
- 일반 한글의 양식 탭은 HWP/HWPX 파일 삽입·새 문서 열기 방식을 유지
- 이전 파일형 기안문 양식은 원본을 보존하고 텍스트로 수정한 뒤 다시 사용 가능

## v.4.1.8

- 자동 서식 설정은 새로 최대 10개까지 저장하도록 제한하고 기존 초과 설정은 불러올 때 보존
- 오래된 백업에서 단일 자동 서식 설정이 기본 프로필로 이전되지 않던 문제 수정
- 자동 서식 중단·실패에 대비해 선택 영역 복구 파일을 만들고 교체형 작업은 원본 자동 복구 시도
- 자동 서식 설정 저장 실패 시 설정창을 유지하고 설치본은 내장 업데이트 설정을 우선 사용

## v.4.1.7

- 자동 서식 설정을 여러 프로필로 저장하고 서식 탭에서 바로 전환하는 기능 추가
- 새 설정 생성·현재 설정 복제·이름 변경·삭제 기능 추가
- 기존 단일 자동 서식 설정을 `기본 설정` 프로필로 자동 이전
- 활성 프로필과 전체 프로필을 기존 설정 백업·복원에 포함

## v.4.1.6

- 설정창에 버전별 변경 내용을 확인하는 `업데이트 내역` 버튼 추가
- 새 버전 설치 후 처음 실행할 때 상단 띠에서 업데이트 내용을 바로 확인하도록 개선
- 새 설치와 기존 사용자 업데이트를 구분해 기존 사용자에게만 설치 완료 안내 표시
- 새 버전 설치파일 준비 시 상단에서 `지금 적용`과 `나중에` 선택
- `나중에`로 숨긴 적용 안내를 앱 재실행 또는 수동 업데이트 확인 시 다시 표시

## v.4.1.5

- 설정·단축키·자동 서식 설정과 내 서식·양식·편집용지·문자표·심볼을 하나의 백업 파일로 저장
- 다른 PC에서 백업 파일을 선택해 설정과 사용자 자료를 한 번에 복원
- 복원 직전 상태를 자동 백업하고 최근 복구본 3개를 보존
- 백업 파일 경로·크기·앱 식별자를 검증하고 임시 파일·캐시·오류 기록은 제외

## v.4.1.4

- 한글 COM 작업이 장시간 응답하지 않을 때 작업을 중단하고 다음 명령에서 백엔드 연결을 새로 시작하도록 개선
- 시간 초과된 수정 명령은 중복 적용을 막기 위해 자동으로 재실행하지 않도록 보호
- 화면에 표시된 명령 실패와 백엔드 전송 오류를 오류 기록에 남기고 로그 크기를 제한하도록 개선

## v.4.1.3

- 표 안의 텍스트 일부 선택과 셀 블록 선택을 구분하도록 글자작업 판정 개선
- 텍스트 선택은 선택 글자에만, 실제 셀 선택은 기존처럼 선택 셀 전체에 적용
- 셀 정리·그림 삽입·표 작업의 기존 셀 범위 추적은 유지
## v.4.1.2

- 서식 수동 지정에서 서식 삽입 직후 줄 끝으로 이동하고 새 문단을 만들도록 변경
- 전체 서식 자동 지정하기에는 적용되지 않도록 수동 서식 전용 경로로 분리
## v.4.1.1

- 현재 문서에 양식을 삽입할 때 양식 파일의 구역·쪽 모양 때문에 다음 페이지로 밀리던 문제 수정
- 글자·문단·스타일·개요 번호 보존은 유지하고 현재 커서 위치에 삽입하도록 개선

## v.4.1.0

- 표에서 여러 셀을 선택한 뒤에도 글꼴·글자 크기·글자색이 모든 선택 셀에 적용되도록 수정
- 문자표에서 특수문자를 삽입한 직후 한글 문서에 계속 입력할 수 있도록 포커스 복귀 수정


## v.4.0.9

- 교육비전 2종을 최신 가로조합형·기본조합형·집약조합형 3종으로 교체
- 슬로건 2종을 최신 2줄·기본형·세로형 투명 PNG 3종으로 교체
- 심볼 탭에 여러 이미지 파일을 직접 등록하는 `내 심볼 추가` 기능 추가
- 사용자 심볼을 앱 데이터에 보존하고 이름 변경·삭제할 수 있는 관리 기능 추가

- 마지막 작업 창의 WindowHandle과 COM 객체를 대조해 기능 적용 대상 정확도 향상
- 기능 실행 직전에 연결 대상을 검증하고 잘못된 인스턴스이면 자동 재연결
- 화면에 보이는 한글이 없을 때 숨은 프로세스에 작업하지 않도록 보호

## v.4.0.7

- 개별 적용 버튼도 저장된 자동 서식 설정과 등록한 제목 양식을 그대로 사용
- 제목에 입력된 기존 순번을 유지하면서 선택한 번호 형식으로 변환
- 블록 미지정 시 안내창 표시, 개별 적용에서는 편집용지 설정을 변경하지 않도록 분리
## v.4.0.6

- 문서제목과 1단계 제목에 사용하는 예시를 일반 내 서식과 완전히 분리
- 한글에서 실제 번호·제목을 넣은 예시 전체를 블록 지정해 역할별로 등록·관리
